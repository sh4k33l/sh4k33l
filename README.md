## About me

I'm a Tier II technical support specialist. I have worked with WordPress since 2014 and in remote product support since 2020, for software used by course creators, event organizers and nonprofits.

- 🔎 I take the escalated cases: deep debugging, PHP errors, plugin conflicts and the ones that need engineering involved
- 🧭 I look for the root cause instead of hiding symptoms behind a temporary patch
- ✍️ I explain the fix in plain language, to the customer and to the developers
- 🛠️ When I see the same problem too many times, I build a tool for it
- 🌍 WordCamp Asia 2023 (volunteer) and 2024, WordCamp Lisbon 2025, WordCamp Europe 2025
